# Firebreak judge video script

**Tagline:** One agent. Four robots. One human-approved rescue boundary.

Target: **2 minutes 10 seconds**, public on YouTube, with narration audio. Record the six clips below separately, then remove every wait and loading moment. Do not type live.

## Recording setup

- Start already signed in to a fresh Codex or ChatGPT chat with GPT-5.6 Sol and Firebreak open in the built-in browser.
- Confirm **WebMCP Native**, **7 tools live**, a clean trace, loaded 3D graphics, and working audio before recording.
- Record the real native-agent path. **Replay walkthrough · no agent** is rehearsal-only and must not appear as AI.
- Paste the two prompts, then jump-cut directly to tool activity. Never show cold start, searching, setup, or a loading screen.
- Keep enough surrounding chat visible to prove the agent is calling site tools. Crop tighter on Firebreak for the cinematic execution.
- Add the suggested on-screen captions in editing. Use a subtle 1.15×–1.35× speed-up only where the real UI remains readable.

> Four rescue robots are moving through one human-approved WebMCP capability. In seconds, that capability will delete itself.

Hold on the unobstructed deterministic receipt: two workers safe, fire contained, load secured, zero violations. Show the collapsed surface reading **7 tools live**, then briefly open the trace if needed to reveal `8 → 7 tools`.

- Show ROS/Gazebo footage only if separately validated. The submitted warehouse is an honest deterministic browser simulation, not certified physical deployment.
